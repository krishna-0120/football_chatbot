# ⚽ Football AI Assistant

A football-focused AI assistant built with **Python** and **Streamlit** that combines an LLM with live football data. The application can answer general football questions while also providing all details until December 2023 information such as team details, league standings, and upcoming fixtures through the Football-Data API.

## 📌 Overview

This project was built to explore how large language models can be combined with real-time sports data to create a more useful chatbot experience. Instead of relying only on AI-generated responses, the assistant detects the user's intent and fetches live football information whenever appropriate.

## ✨ Features

- 💬 AI-powered football conversations using the Groq API
- 📊 Live league standings
- 🏟️ Team information
- 📅 Upcoming fixtures
- ⚽ Recent match results
- 🧠 Intent detection for football-related queries
- 💾 Export chat history
- 🎨 Clean and responsive Streamlit interface

## 🛠️ Tech Stack

- **Python**
- **Streamlit**
- **Groq API (Llama 3.3 70B)**
- **Football-Data.org API**
- **Requests**
- **Python Dotenv**
